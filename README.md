### 合租/家庭/旅行共享账本与分摊系统

**真实痛点**：合租水电、旅行 AA、家庭共同开支，靠微信群和表格记账，月底算不清谁欠谁。用户就是你们自己或朋友，访谈成本极低。

**范围收敛**：
- 必做：创建账本 → 邀请成员 → 记一笔支出（金额、付款人、参与人、分摊方式）→ 均摊/自定义分摊计算 → 结算建议（谁转给谁多少钱）。
- 本轮不做：真实支付、银行卡绑定、多币种、发票 OCR、信用体系。
- 人工兜底：争议账目由成员线下协商，系统只记录和计算，不做仲裁。

**可验证标准**：准备 5 条支出记录，手工算出结算结果，系统输出必须一致；成员只能看自己参与的账本，越权访问被拦截；删除/修改记录后结算结果同步正确。

**风险控制**：不碰资金流，只做“记账和算账”；数据最小化，不收集身份证、银行卡。
